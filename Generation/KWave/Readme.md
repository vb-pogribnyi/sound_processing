# KWave signal generator
This module contains code for creating synthetic signal using KWave tool. 
The module consists of several parts:
- generator of a base mesh - a map where acoustic pressure will be generated by a rotor blade
- KWave binary - a modified binary that that applies input base mesh in a loop and saves pressure maps at specified sample rate
- main module that runs pre-defined configuration (yaml-experiment)
- exporter that converts the pressure maps into a signal captured with a microphone array of given configuration.

## Export base mesh
Before simulation can be made, a base mesh should be generated. Inside ```/app/Generation/KWave/CircularSignal/profiles``` multiple profiles are collected. Each image in a profile displays how large acoustic pressure will be generated at certain point by the moving blade

## Run container
The module is meant to be launched in a docker container. The KWave input data is meant to be re-written frequently, so a RAM-based tmpfs directory is used for it. Two variants are presented below. One for smaller experiment volume and mesh step of 0.002 m - with tmpfs size=8G. The other one is for larger volume and mesh size of 0.008 m. Since mesh step is larger, the base mesh takes less mesh cells and more timesteps can fit into single run, so the tmpfs needs to be larger at size=24G.
``` bash
docker run --gpus all --name kwave --shm-size=8G -v /home/vitalii/Desktop/Projects/KWave:/app -v /media/vitalii/Data/Experiments:/experiments --tmpfs /inputs:size=8G -it kwave:25apr2026 bash
docker run --gpus all --name kwave --shm-size=8G -v /home/vitalii/Desktop/Projects/KWave:/app -v /media/vitalii/Data/Experiments:/experiments --tmpfs /inputs:size=24G -it kwave:25apr2026 bash
```
Compile kwave as:
``` bash
cd /app/k-Wave-CPUGPU-src/kspaceFirstOrder-CUDA
make -j
```
